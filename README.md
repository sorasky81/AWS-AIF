# AWS-AIF 暗記ドリル

AWS 認定 AI プラクティショナー（**AIF-C01**）の試験対策用 Web アプリ。
手元の暗記リスト PDF をデータ化し、ブラウザ上でカード・4択・弱点復習ができるようにしたもの。

## 使い方

`index.html` をブラウザで開くだけ。ビルド・サーバー・インターネット接続いずれも不要（Web フォントのみ CDN から読み込み）。

```
index.html            アプリ本体（HTML / CSS / JS / データすべて内包・1ファイル完結）
AIF暗記リスト.pdf       データの元になった暗記リスト
```

## 収録内容

## モード

- **カード** — 名前→説明 / 説明→名前 を切替。「もう一度」「覚えた」で仕分け。裏面にその項目が登場する「見分け方」ラインも表示
- **4択** — 10問1セット。①説明→サービス ②サービス→説明 ③見分け方の穴埋め、の3タイプ
- **一覧** — 全項目をセクション別に通し読み＋検索
- **弱点** — 「もう一度」を付けた項目と4択で間違えた項目が自動で集まり、そこだけ再テストできる

誤答の選択肢は同じセクション内から優先的に生成されるため、Comprehend / Textract / Kendra のような紛らわしい組み合わせが必ずぶつかるようになっている。

## キーボード操作

| キー | 動作 |
|---|---|
| `Space` | カードをめくる |
| `1` / `2` | もう一度 / 覚えた |
| `←` `→` | 前のカード / 次のカード |
| `1`〜`4` | 4択の解答 |
| `Enter` | 次の問題へ |

## メモ

- 学習の進捗は `localStorage` に保存されるため、ブラウザごと・端末ごとに独立する
- ライト／ダークテーマ対応、スマートフォン幅でも利用可
- 13章の評価指標（GLUE・BLEU 等）と 16章の S3 安い順チェーンは、1行に複数サービスがまとまった記述のため穴埋めクイズの対象外（一覧での表示のみ）
